# Agent personas

1. Read `docs/product.md` for the product, then `docs/team.md` for house rules and the pipeline.
2. Pick **one** persona.
3. **Source Librarian** or **Trust Auditor**: launch that Cursor agent (`.cursor/agents/`). Pack one job, constraints, paths, what to return. Do not do the job in the parent.
4. Any other persona: read only that file under `docs/personas/` and do the job.
5. If a billed model is needed, pack the same way.

Do not mix two personas in one pass. Do not skip Trust Auditor on citizen-facing work.
